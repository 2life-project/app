# Дизайн-токены

Все размеры и цвета приложения живут в `src/shared/theme`. В продуктовом коде
литеральных значений нет — это проверяет линтер, а не ревьюер.

```ts
import { color, spacing, radius, shadow, textVariant, duration, easing } from '@/shared/theme';
```

## Два слоя цвета

**`palette.ts` — пигменты.** Значения один-в-один с вебом (`frontend/src/styles/tokens.css`).
Меняются только вместе с вебом. В компонентах палитру не импортируют.

| Семейство       | Роль в продукте        |
| --------------- | ---------------------- |
| `sky` 50–900    | фон, действия, акцент  |
| `leaf` 100–700  | статус «в норме»       |
| `sun` 300–500   | статус «на границе»    |
| `coral` 300–500 | статус «вне референса» |
| `ink` 100–900   | текст и границы        |

**`colors.ts` — роли.** То, чем пользуются компоненты: `color.text`, `color.surface`,
`color.border`, `color.accent`, `color.status.watch.fill`. Имя говорит о назначении,
а не о пигменте: перекраска продукта не должна означать правку сотни файлов.

`color.backdrop` — градиент фона экрана, снизу трава, сверху небо. Его рисует
`<Screen>`; экраны свой фон не задают.

## Текст

Кегли не пишут руками — есть роли:

| Роль       | Где                               |
| ---------- | --------------------------------- |
| `display`  | заголовок экрана                  |
| `title`    | заголовок блока                   |
| `subtitle` | заголовок карточки                |
| `body`     | основной текст                    |
| `label`    | подписи, кнопки                   |
| `caption`  | мелкое служебное                  |
| `metric`   | крупное число, моноширинные цифры |

```tsx
<Text variant="subtitle">Загрузите первый анализ</Text>
<Text tone="soft">Соберём показатели в одну картину.</Text>
```

Тон — `default`, `soft`, `faint`, `accent`, `onAccent`.

Гарнитура — системная (`fontFamily.ui`). Веб живёт на Segoe UI / Frutiger, на телефоне
такого шрифта нет, а тянуть веб-шрифт ради похожести дорого: системный даёт нативный
ритм и нулевую загрузку. Если дизайн зафиксирует конкретную гарнитуру — правится
`typography.ts` и добавляется загрузка через `expo-font`; вызовы `<Text>` не меняются.

Числа в метриках идут с `fontVariant: ['tabular-nums']`, чтобы колонки не дёргались
при смене значения.

## Размеры

`spacing` — шаг 4pt: `xs 4`, `sm 8`, `md 12`, `lg 16`, `xl 24`, `xxl 32`, `xxxl 48`.
Отступы задаются через `<Stack gap="lg">`, а не россыпью `margin` по компонентам.

`radius` — `sm 10`, `md 16`, `lg 24`, `xl 34`, `pill`. Значения из веба.

`shadow` — CSS-строки для `boxShadow`: RN 0.86 понимает их на всех платформах,
поэтому тени перенесены из веба дословно, без пары iOS/Android-веток.

`screenPadding` — боковые поля экрана, одно значение на приложение.
`hitSize` — 44pt, минимальная зона нажатия.

## Анимация

`duration` — `instant 120`, `fast 180`, `base 240`, `slow 320`. Дольше 320 мс
интерфейс начинает казаться медленным.
`easing.liquid` — основная кривая продукта, `easing.gel` — пружина для появления.

## Как добавить токен

1. Сначала проверь, что подходящего нет. Новый оттенок «чуть темнее» почти всегда
   означает, что не нашли существующий.
2. Пигмент → в `palette.ts`, но только если он согласован с дизайном и вебом.
3. Роль → в `colors.ts` / `textVariant` / `spacing`. Имя по назначению, не по виду.
4. Экспорт добавляется в `src/shared/theme/index.ts`.
5. `make test` — инварианты токенов (разбираемые цвета, кратность шага, интерлиньяж
   не меньше кегля) проверяются в `src/shared/theme/theme.test.ts`.

## Что запрещено

- `'#2ba6e0'` где угодно, кроме `src/shared/theme/**` — ошибка линтера.
- `fontSize: 15` в компоненте вместо `variant`.
- `margin: 13` вместо шага `spacing`.
- Вторая палитра и `useColorScheme`: тёмной темы нет by design.
