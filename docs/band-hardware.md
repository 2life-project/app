# ES100: железо и датчики

Что физически стоит в браслете и что из этого доступно по протоколу. Три
источника, и они помечены отдельно: **[живое]** — снято с устройства командами,
**[SDK]** — из заголовков вендора, **[внешнее]** — из открытых источников по
платформе. Наблюдения глазами помечены **[глаз]**.

---

## 1. Паспорт **[живое]**

| Параметр              | Значение            |
| --------------------- | ------------------- |
| Адрес                 | `D8:0F:B5:11:2E:F7` |
| Платформа             | `NAL-WB00`          |
| Аппаратная версия     | `010404`            |
| Прошивка              | `AT519V003396`      |
| Версия протокола      | `V1.0`              |
| Серийный              | `V1.0`              |
| Максимальный пакет    | 244 байта           |
| Заряд на момент съёма | 93 %                |

`NAL-WB00` — **не модель, а идентификатор платформы**. Его же отдают DM58,
Blackview W60, Carbinox Blaze S, Zeblaze Stratos 4 и HONOR CHOICE MOECEN Band.
Строка модели в стандартной службе у всех одна: `lark`. **[внешнее]**

## 2. Оптический датчик

### Что видно глазами **[глаз]**

- **два зелёных** светодиода — горят и мигают почти всё время;
- **два приёмника** (фотодиода) между ними;
- **красный** — виден периодически, точки различимы;
- периоды, когда «ничего не горит», — это **инфракрасный**: он невидим;
- синего не наблюдалось.

### Что следует из измерений **[живое]**

Устройство отдаёт **SpO₂** — насыщение крови кислородом. Оно считается по
отношению поглощения на двух длинах волн: **красной (~660 нм) и инфракрасной
(~940 нм)**. Одним зелёным каналом SpO₂ не считается физически. То есть красный
и ИК присутствуют не по наблюдению, а по необходимости.

Зелёный (~525 нм) — рабочая длина волны пульсометра: он меньше уходит вглубь и
устойчивее к движению.

### Что из этого выводится, а не измеряется

| Показатель           | Откуда берётся                                     |
| -------------------- | -------------------------------------------------- |
| Пульс                | форма пульсовой волны, зелёный канал               |
| SpO₂                 | отношение красного и ИК каналов                    |
| Вариабельность (HRV) | интервалы между ударами из той же волны            |
| Стресс               | производная от HRV, отдельного датчика нет         |
| Давление             | форма волны плюс калибровка, отдельной манжеты нет |
| Настроение           | производная, шкала устройства 1–5                  |

Четыре последних строки — **расчёт по одной и той же пульсовой волне**, а не
четыре разных сенсора. Точность у таких оценок соответствующая.

### Чего нет

**ЭКГ отсутствует.** Для неё нужны электроды на корпусе и разность потенциалов
между двумя точками тела — оптикой ЭКГ не снимается. В масках возможностей ЭКГ
не заявлена.

## 3. Термометр

**Датчик по протоколу недоступен. [живое]**

Два независимых подтверждения:

1. Бит `temperature` в масках возможностей **сброшен** (список 4, бит `0x200`).
2. Команды чтения температуры не отвечают вовсе:
   - `01 FB AA 01` — текущая: нет ответа;
   - `01 FB AA 02` — история за двое суток: нет ответа.

При этом в SDK вендора флаги термометра **есть** — `isHasBodyTemperature`,
`isHasCalibrateBodyTemperature`, `isHasSwitchTempUnit`, `isHasBodyTemperatureFunction2`
**[SDK]**. То есть в линейке термометр бывает, а в этой прошивке он выключен или
не установлен.

Косвенно о типе: наличие **пользовательской калибровки** в SDK — признак
контактного термистора под кожу, а не медицинского инфракрасного модуля.
Термистор меряет температуру кожи, и без калибровки под конкретного человека его
показания к температуре тела отношения не имеют. **[внешнее]**

Проверить, есть ли термистор физически, можно только вскрытием.

## 4. Движение

**Акселерометр есть заведомо:** без него не считаются ни шаги, ни дистанция, ни
стадии сна, ни распознавание активности — а всё это устройство отдаёт. **[живое]**

**Гироскоп — вероятен, но по протоколу не подтверждается.** Сырые оси движения
протокол не отдаёт вовсе, отдельного флага гироскопа в масках нет.

Аргумент за его наличие косвенный, но сильный: устройство **само распознаёт
активность** — пишет отрезки движения без всякой команды, и длинные из них
совпадают с окном реальной тренировки. Библиотека распознавания активности,
которую Actions поставляет в своём SDK для этой платформы (CyweeMotion AI
Motion), требует **шестиосевого** датчика — акселерометр плюс гироскоп.
**[внешнее]**

В заводских флагах SDK гироскоп проходит **опцией**: `isHasFactoryTestGsensor`
есть всегда, `isHasFactoryTestGyro` — отдельным флагом. То есть в линейке
встречаются оба варианта. **[SDK]**

## 5. Прочее железо **[живое + SDK]**

| Узел                | Есть | Откуда известно                                          |
| ------------------- | ---- | -------------------------------------------------------- |
| Микрофон            | ✓    | диктофон работает, Opus 16 кГц                           |
| Вибромотор          | ✓    | команда «найти браслет» отрабатывает                     |
| Светодиод-индикатор | ✓    | двухцветный, виден глазами                               |
| Экран               | ✗    | бит `noScreen` взведён                                   |
| Динамик             | ✗    | звук наружу не выводится                                 |
| GPS                 | ✗    | бит сброшен, трек пуст                                   |
| NFC                 | ✗    | в масках не заявлен                                      |
| Магнитометр         | ✗    | в масках не заявлен                                      |
| Bluetooth Classic   | ✗    | бит `noBluetoothCall` взведён — звонки не поддерживаются |

**Процессор — Actions ATS3085L или ATS3085S. [внешнее]** Cortex-M4F до 240 МГц,
Bluetooth 5.3, встроенный сенсорный хаб и отдельный малошумящий стабилизатор
питания специально под оптический пульсометр. Флаги платформы
`IS_PLATFORM_JXATS3085L` / `IS_PLATFORM_JXATS3085S` присутствуют в SDK вендора.

## 6. Маски возможностей: что заявляет само устройство **[живое]**

Прочитаны с характеристик `35F1` и `34F1`:

```
35F1  80 00 00 00 00 00 00 00 50 0d 80 80 00 00 4e 00 01 00 00 00
34F1  00 f4 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 20
```

Разобранные списки:

```
список 2 = 0x4E0001    список 4 = 0x500D80    список 8 = 0x000020
список 3 = 0x800000    список 7 = 0x008000    максимальный пакет = 244
```

| Возможность               | Есть | Комментарий                                     |
| ------------------------- | ---- | ----------------------------------------------- |
| Диктофон                  | ✓    | подтверждено работой                            |
| Вариабельность пульса     | ✓    |                                                 |
| Давление                  | ✓    | расчётное, по пульсовой волне                   |
| Настроение                | ✓    | шкала 1–5, значения вендором не документированы |
| Расширенные будильники    | ✓    |                                                 |
| Расширенная история       | ✓    | меняет номер поля в запросе счётчика кадров     |
| Голос офлайн              | ✓    | **бит взведён, смысл не установлен**            |
| Нет экрана                | ✓    |                                                 |
| Нет звонков по BT Classic | ✓    |                                                 |
| Термометр                 | ✗    | и командами не отвечает                         |
| Музыка                    | ✗    |                                                 |
| Распознавание речи        | ✗    | на устройстве не делается                       |
| ChatGPT                   | ✗    |                                                 |
| GPS                       | ✗    |                                                 |

**Про «голос офлайн».** Бит взведён, но команд под него в протоколе не нашлось, а
распознавание речи при этом выключено. Что именно за ним стоит — не установлено;
выдавать это за офлайн-транскрипцию нельзя.

**Четыре бита не опознаны:** список 2 биты 0 и 22, список 4 бит 10, список 7
бит 15, список 8 бит 5. Что они означают, в доступных источниках не описано.

## 7. Текущие настройки датчиков **[живое]**

| Настройка              | Значение                                  |
| ---------------------- | ----------------------------------------- |
| Непрерывный пульс      | включён                                   |
| Интервал замера пульса | 1 минута                                  |
| Интервал замера SpO₂   | 10 минут                                  |
| Верхний порог пульса   | 180 уд/мин, тревога включена              |
| Нижний порог пульса    | 50 уд/мин, тревога выключена              |
| Сахар в крови          | заявлен, датчика нет — поле всегда пустое |
| Состояние ношения      | надет                                     |
| Погода                 | выключена                                 |

**Темп живого канала — ровно 10 секунд**, и он не меняется при движении.
Меняется набор показателей: в покое приходит пульс (покоя, максимальный,
минимальный, средний), при движении — SpO₂. Проверено наблюдением 90 секунд.

## 8. Чего установить не удалось

1. **Точное число светодиодов и фотодиодов** — протокол об этом не сообщает,
   teardown ES100 в открытых источниках нет.
2. **Есть ли гироскоп физически** — только вскрытием или запросом вендору.
3. **Есть ли термистор физически** — по протоколу он недоступен, это всё, что
   известно.
4. **Смысл бита «голос офлайн»** и четырёх неопознанных битов.
5. **Ёмкость батареи в мА·ч** — устройство отдаёт только проценты.
