# Решения

Два списка: что решено и не пересматривается по ходу дела, и что сознательно
не сделано — с условием, при котором это надо делать.

Смысл второго списка в том, чтобы следующий человек или агент не изобретал
заново то, что уже обсуждали, и не строил заранее то, для чего ещё нет
потребителя. Появился триггер — правка идёт по плану, а не с нуля.

## Принято

Эти решения меняются только явным решением владельца, не по ходу задачи.

| Решение                                                                                                                                                                                                             | Почему                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Expo вместо голого React Native CLI                                                                                                                                                                                 | Обновления SDK одной командой, сборка без локального Xcode, нативные модули через dev build                                                                                                                                         |
| expo-router вместо ручного react-navigation                                                                                                                                                                         | Маршрут = файл, типизированные ссылки, deep links из коробки                                                                                                                                                                        |
| Слои `app → features → shared → core`                                                                                                                                                                               | Урезанный Feature-Sliced Design: три его слоя плюс инфраструктура. `entities` и `widgets` заводятся, когда начнут окупаться                                                                                                         |
| Токены обычным TypeScript, без библиотеки стилей                                                                                                                                                                    | `StyleSheet` и импорт темы дают то же без нативного модуля и babel-плагина                                                                                                                                                          |
| Цветовые шкалы считаются генератором                                                                                                                                                                                | Он кодирует то, что из статики не восстановить: равномерность OKLCH, подгонку заливки под контраст, порядок ступеней, слот под фирменный цвет                                                                                       |
| Одна тема                                                                                                                                                                                                           | Тёмной не будет, пока нет её макета: провайдер и хук ради одной темы — сложность в каждом компоненте без потребителя                                                                                                                |
| Номера сборок на стороне EAS                                                                                                                                                                                        | В репозитории их нет — конфликтовать нечему                                                                                                                                                                                         |
| Загрузка файлов мимо HTTP-клиента                                                                                                                                                                                   | Тело клиента только JSON; файл требует прогресса и продолжения в фоне, это другой механизм                                                                                                                                          |
| Интерфейс по-английски, комментарии и логи по-русски                                                                                                                                                                | Макет на английском, и раздел браслета приведён к нему же: двуязычный экран хуже любого из двух языков. i18n вводится по триггеру ниже                                                                                              |
| Тесты — юниты и инварианты, без снапшотов вёрстки                                                                                                                                                                   | Снапшот вёрстки ловит любое изменение и потому не ловит ничего                                                                                                                                                                      |
| Показания браслета — доменная сущность в `shared/domain`                                                                                                                                                            | Их читают Главная, «Тело», Журнал и настройки, а фича фиче не видна. Считает итоги одно место: разойдись счёт, человек увидел бы два разных числа шагов за день                                                                     |
| Браслет — второй источник рядом с сервером, а не замена                                                                                                                                                             | Что устройство измеряет само (пульс, сон, дыхание, шаги) — берётся с него; оценки, шкалы и нормы остаются серверными. Множества не пересекаются, поэтому правила приоритета не нужно                                                |
| Интерфейс приложения — по-английски: вкладки, подписи, кнопки                                                                                                                                                       | Так решил Антон 11 сентября 2026. Контент сервера приходит на языке аккаунта, и подписи не должны спорить с ним третьим языком. Названия языков в настройках остаются на своём языке                                                |
| Карточки браслета живут в разделах: пульс — в «Сердце», кислород — в «Дыхании», сон и стресс — в «Восстановлении», шаги и занятия — в «Активности» на Главной. Раздел получает их слотом, который заполняет маршрут | Человек ищет пульс там, где сердце, а не на экране устройства. Фичи друг друга не импортируют, компоновать может только маршрут — он единственный видит обе. Экран устройства остаётся про связь, команды и записи                  |
| Профиль тела живёт в `shared/domain`, правится в одном месте и уезжает на сервер и на устройство                                                                                                                    | Без роста, веса, пола и возраста браслет считает по заводским значениям, а приложение читает результат как измеренный факт; сервер главный, телефон дозаполняет пустое у него и помнит неотправленную правку                        |
| Событие журнала — доменная сущность в `shared/domain`                                                                                                                                                               | Его читают Журнал и Главная (тренировка из ленты) одной ручкой; форма и запросы одни, чтобы экраны не разошлись на первом же поле                                                                                                   |
| Очередь на сервер ключуется аккаунтом и браслетом                                                                                                                                                                   | Телефоном пользуются двое; накопленное одним нельзя отправить от имени другого. Выход из аккаунта очередь не стирает — она дошлётся при следующем входе                                                                             |
| Связь с браслетом живёт на уровне приложения                                                                                                                                                                        | Экран её только показывает: уход с него не рвёт соединение, обрыв ставит новое подключение, пуши обрабатываются и в фоне. На iOS ожидающее подключение не истекает, а идентификатор восстановления поднимает приложение из выгрузки |
| Записи диктофона лежат в папке аккаунта                                                                                                                                                                             | Файл не помнит, кто его наговорил; без своей папки записи первого человека уехали бы на сервер под именем второго, вошедшего на том же телефоне                                                                                     |
| В релизе виден только `logger.error`                                                                                                                                                                                | Отказ, которого не записал общий HTTP-клиент, — сеть, хранилище, Bluetooth — пишется через `reportFailure`/`error`; `warn` — для того, что уже записано или ожидаемо                                                                |

## Отложено — с триггером

Ни одно из этого не строится «пока не забыли». Каждое ждёт своего условия.

| Что                                                | Триггер                                              | Почему не сейчас                                                             |
| -------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------- |
| Контракт route-файла: `options`, параметры пропсом | Первый экран с параметром маршрута или заголовком    | Выбирать между тремя способами без реального случая — угадывание             |
| Хелперы навигации между фичами                     | Вторая ссылка из фичи в чужой экран                  | Переходов между фичами пока нет                                              |
| Шов авторизации в HTTP-клиенте                     | Первый защищённый эндпоинт                           | Форму шва задаёт реальный контракт токена                                    |
| Клиент серверного состояния                        | Первый экран со списком с сервера                    | Иначе три состояния экрана будут написаны руками по-разному                  |
| Офлайн-кэш                                         | Экран, который обязан работать без сети              | В первую очередь это выжимка для врача                                       |
| Крэш-репортер                                      | Первый тестер за пределами команды                   | Смысл раннего билда — узнать, что ломается; без репортера он этого не даёт   |
| OTA-обновления                                     | Подготовка первого релиза в стор                     | Политика версии вшивается в бинарник, менять её потом больно                 |
| i18n                                               | Второй язык в плане                                  | Сейчас переносить нечего; после продуктовых экранов цена вырастет на порядок |
| Тёмная тема                                        | Макет тёмной темы                                    | Возврат стоит второй карты ролей и перевода компонентов на хук               |
| E2E-сценарии                                       | Первый сквозной путь, который ломается при рефакторе | Юниты и сборка бандла пока покрывают больше за меньшее                       |
| Витрина компонентов                                | Примерно двадцать компонентов в `shared/ui`          | На семи её проще держать в голове, чем поддерживать                          |

## Известные заглушки

Это не решения, а долг, о котором надо помнить.

- Предсобранные нативные модули Expo выключены (`ios.usePrecompiledModules`).
  Они собраны против динамического `React.framework`, а React в нашей сборке
  статический — приложение падало на старте с `dyld: Library not loaded`.
  Плата — первая сборка дольше: модули компилируются из исходников.
- **Крэш-репортера нет, а его триггер уже сработал.** Первый тестер за
  пределами команды прислал два отчёта подряд: приложение закрылось, а потом
  перестало открываться. Сообщения самой ошибки JS в отчёте TestFlight нет —
  там только native-стек. Вместо репортера сейчас стоит самодельная замена:
  ошибка не убивает приложение, а показывает экран с текстом и следом
  последних событий, который тестер присылает снимком. Это заплатка на один
  заход, а не решение: репортер отдаёт то же самое без участия человека.
- Иконка и сплэш — из шаблона Expo. Заменить до того, как сборку увидит
  кто-то снаружи команды: в TestFlight она уже видна.
- Вход через Google и Apple: кнопки есть, входа нет. Сервер умеет обменять
  их токены, но идентификаторы приложения у него не настроены (`503`), а на
  телефоне нет нативных SDK, которые токен выдают. Нажатие говорит об этом
  прямо; включается, когда бэк настроит идентификаторы.
- Что делается только в вебе, потому что требует OAuth с сессией веб-приложения
  или выбора файла: подключение чужих трекеров, загрузка документов и
  генетических файлов, расписание курса по дням. Телефон показывает
  состояние и ведёт туда словами.
- Действия без своего экрана в макете — «Edit», «Learn more», «Set up
  firmware» — нажимаются, но пока ничего не открывают: придумывать им экран
  значит расходиться с макетом.
- Показания браслета уезжают на сервер, но обратно не читаются: второй телефон
  на том же аккаунте увидит пустой раздел, пока не подключит браслет сам.
  Результат разбора пачки сервером пишется только в лог — экрана для него нет.
- Общий слой держит показания за сегодня. Прошлые сутки лежат в архиве раздела
  устройства и на других экранах не показываются: листать историю по дням
  пока негде.
